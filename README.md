# JavaScript Fundamentals Exercises

A collection of 20 JavaScript programming exercises developed to practice fundamental programming concepts through practical and interactive problems. The exercises cover variables, operators, calculations, user input, conditional statements, menus, conversions, discounts, and simple interactive applications.

## Objective

The main objective of this project is to strengthen programming fundamentals through practical JavaScript exercises, applying basic concepts to solve different types of problems and develop logical thinking.

## Features

* User input using `prompt()`
* Results and messages displayed with `alert()`
* Basic arithmetic operations
* Average and mathematical calculations
* Conditional statements and decision-making
* Number and value comparisons
* Even and odd number verification
* Menus and option selection
* Unit and temperature conversions
* Purchase calculations and discounts
* Payment method processing
* Basic classification systems
* Simple interactive applications

## Technologies

* JavaScript
* HTML5

## Concepts Applied

The exercises provide practical applications of fundamental JavaScript concepts, including:

* Variables and constants
* Data types and type conversion
* Arithmetic and comparison operators
* Conditional statements (`if`, `else if`, `else`)
* Logical operators
* User input and output
* Mathematical formulas
* Menu-based interactions
* Basic program logic and decision-making

## Academic Context

This project was developed as part of academic activities in the **Software Engineering** course, focusing on the practical application of introductory programming concepts using JavaScript.

The exercises were designed to progressively practice programming logic, starting with simple calculations and gradually introducing conditional structures, menus, validations, and more complete interactive applications.
