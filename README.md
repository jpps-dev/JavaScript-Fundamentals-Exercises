# JavaScript Fundamentals Exercises

A collection of 20 JavaScript exercises developed to practice programming fundamentals through practical and interactive problems. The activities gradually introduce calculations, user input, conditional logic, comparisons, menus, conversions, discounts, and basic decision-making.

## About

This repository contains a series of introductory JavaScript exercises created as part of academic programming activities in the **Software Engineering** course.

The exercises are organized progressively, starting with basic mathematical operations and simple calculations and advancing to conditional structures, option-based menus, validation, discounts, payment methods, and small interactive applications.

The main purpose of the project is to reinforce programming logic and provide practical experience with fundamental programming concepts using JavaScript.

## Concepts Practiced

Throughout the exercises, different fundamental programming concepts are applied, including:

* Variables and constants
* User input and program output
* Data types and type conversion
* Arithmetic operators
* Comparison operators
* Logical operators
* Conditional statements
* `if`, `else if`, and `else`
* Mathematical calculations and formulas
* Modulus operator
* Menu-based interactions
* Input validation
* Decision-making and program flow
* Discounts and final value calculations

## Technologies

* **JavaScript** — Used to implement the programming logic and interactive functionality.
* **HTML5** — Used as the basic environment for loading and executing the JavaScript files.

## Interaction

The exercises use JavaScript's built-in browser functions to interact with the user.

* `prompt()` is used to receive values and choices from the user.
* `alert()` is used to display results, messages, and calculated values.

This approach keeps the exercises focused on programming logic rather than interface development.

## How to Run

1. Clone or download this repository.
2. Open any exercise folder, from `Ex01` to `Ex20`.
3. Open the corresponding `index.html` file in a web browser.
4. Follow the instructions displayed through the prompts.
5. View the results through the alerts.

Each exercise is independent and can be executed separately.

## Academic Context

This project was developed for academic practice in the **Software Engineering** course at **IFPR**.

The activities focus on strengthening programming fundamentals and logical reasoning through increasingly structured problems. The progression from simple calculations to interactive menu-based programs provides practical experience with the basic building blocks of programming.
